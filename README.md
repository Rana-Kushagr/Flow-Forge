## ⚡ The 80/20 Productized Architecture

FlowForge is engineered around an **80% reusable deterministic core** with a **20% client configuration layer**, avoiding bespoke code sprawl while delivering measurable ROI from Day 1.

```
FlowForge/
├── src/
│   ├── core/                      # 80% Reusable Foundation
│   │   ├── llm-provider.js        # Gemini API client with intelligent local fallback
│   │   ├── rag.js                 # In-memory semantic/keyword retrieval knowledge base
│   │   └── validator.js           # Schema normalizer (+E.164 phones, emails, currencies)
│   ├── systems/                   # The 3 Signature Systems
│   │   ├── speed-to-lead/         # Sub-60s qualification, FAQ RAG & Cal.com booking
│   │   ├── inbox-triage/          # Categorization, CRM extraction & auto-drafting
│   │   └── data-janitor/          # Normalization, deduplication, schema validation
│   ├── presets/                   # Beachhead Niche Configurations
│   │   ├── local-services.json    # Healthcare / Real Estate presets
│   │   ├── ecommerce-d2c.json     # Order tracking & returns presets
│   │   └── b2b-agency.json        # Budget screening & qualification presets
│   ├── audit/                     # The Trojan Horse Offer
│   │   ├── bottleneck-audit.js    # Operational decay model & ROI calculator
│   │   └── cli-audit.js           # CLI audit runner (npm run audit)
│   └── server/                    # Web Application & API
│       ├── app.js                 # Express REST & Telemetry Server
│       └── public/                # Matte Industrial Swiss Grid Website
│           ├── index.html
│           ├── style.css
│           └── app.js
├── tests/                         # Node.js native test suite (100% passing)
├── package.json
└── README.md
```

## 🚀 Quickstart

### 1. Installation
```bash
npm install
```

### 2. Run the Production Web Application
```bash
npm start
# Server online at http://localhost:3000
```

### 3. Run the 15-Minute Bottleneck Audit (CLI)
```bash
npm run audit "Apex Dental Practice" 150 4 1200 16
```

### 4. Execute the Automated Test Suite
```bash
npm test
```
